# Glossary

| Term | Meaning |
|---|---|
| Protocol | An entry in the explorer. `kind: protocol` for real protocols, `kind: pattern` for architecture patterns such as RAG |
| Family | Group a protocol belongs to (web, transport, naming, mail, ai…); drives its colour and search |
| Scenario | The concrete story a protocol entry plays: its nodes, links, stages and packets |
| Node | A machine or actor in the scenario (client, router, DNS resolver, MCP server, agent…) |
| Stage | A numbered step of the scenario shown in the stage bar; groups packets |
| Packet | One message in the scenario; drives the diagram animation, the sequence arrow and the table row |
| Player | Play / pause / step / reset / speed control over the packet timeline |
| Locale | One UI language (BCP 47 tag, e.g. `el`, `zh-Hans`) |
