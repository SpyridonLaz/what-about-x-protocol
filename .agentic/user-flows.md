# User flows

1. **Watch a protocol (visitor):** open site → HTTP loads by default → press Play → packets animate, table rows highlight, stage bar advances.
2. **Pick another protocol (visitor):** drawer or search (`/` or Ctrl+K) → choose → URL becomes `#/p/<id>` → scenario resets.
3. **Step through (visitor):** Step / ‹ › → one packet at a time; click a table row or stage to jump there.
4. **Switch view (visitor):** Network ↔ Sequence; player position is kept.
5. **Change language (visitor):** auto-detected on first visit → language menu → choice remembered.
6. **Change theme (visitor):** sun / moon buttons → choice remembered.
