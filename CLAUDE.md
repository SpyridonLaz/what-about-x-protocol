# Protocol Explorer

Interactive website that teaches how internet and AI protocols work: animated network diagram, sequence view, packet table and step-by-step player, in English, Greek and German. Static site (Vite + TypeScript, no framework) for GitHub Pages.

Shared knowledge for this project lives in `.agentic/` next to this file. Start at `.agentic/AGENT.md`; it has the reading order and hard rules. Open questions are in `.agentic/decisions.md` → Open.

Workspace-wide preferences and lessons: `../.agentic/AGENT.md`.
